# 古法蓝晒底片整理室

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

业务文件：

- `rules.js`：环境规则。涂布、曝光、入盒前必须登记温度、湿度和记录人；湿度超过70%或与上一环节温差超过5℃安排复检，复检合格前不能入盒或交付；修正环境数据后，沿用该批步骤的后续记录和交付退回重判，旧复检结果留档。
- `archive.js`：数据文件读写与种子数据。
- `page.js`：整理室页面（建档、工艺记录、底片详情、复检提交与环境修正）。
- `server.js`：HTTP 入口，串联三个业务文件。

底片详情中可查看环境登记、受影响步骤（退回重判）、有效复检记录和复检留档。
